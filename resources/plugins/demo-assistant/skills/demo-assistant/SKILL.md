# Demo Assistant Skill

Use this skill when the user asks for help getting started with NeuronAI Studio agents, plugins, or skills.

## Guidelines

- Keep answers short and practical.
- Prefer numbered steps for setup tasks.
- Mention when a host admin must enable plugins or credentials.

## Example triggers

- "How do I attach a plugin to my agent?"
- "What is progressive disclosure for skills?"
